# 腕部 D405 转接座（让腕部相机看清整个夹爪）

## 问题

新 URDF `wheel_robot_26.8.16_3` 的夹爪上，D405 装在一根弯折钣金条的顶面小平台上（CAD：`robots/franzi/assets/urdf/meshes/left_gripper_link.STL`，左右夹爪是同一个零件）。钣金条从法兰附近的底板伸出，平台在壳体外侧 62.7 mm、离夹爪连杆平面很远的高处。

- 相机竖直朝下，光轴和夹爪轴线平行；镜头在抓取点后方 126 mm、夹爪中面外 64 mm。
- 结果：壳体挡住了夹块，两根手指只露出指尖，贴在画面最下沿（`wrist_views.png` 左列）。
- 2026-10-24 给旧夹爪（`wheel_robot_4.0`）设计的倾斜相机块挂在旧 L 形支架的叉耳销轴上。新夹爪没有这个支架，那个块装不上去。2026-10-25 用户要求：新夹爪也要能看到整个夹爪，可以重新设计一个支架，也可以直接沿用旧块的视角。

## 方案

只加一个打印件：装在钣金条顶面平台上，占用 D405 原来的位置和那两颗螺钉。机器人上不用打孔，也不用改其他零件。

- 底座 16 × 30 × 8 mm，坐在平台上（平台 8.4 × 24 mm，厚 3 mm）。底面在平台的两个孔（沿夹爪开合方向，间距 20 mm）正下方各压一个 M3 热熔铜螺母（孔 Ø4.0，深 5.7 mm）。原来固定 D405 的两颗 M3 螺钉从平台下方穿上来，拧进铜螺母。
- 腹板宽 12 mm，从底座斜着往夹爪方向伸出，顶端是 30 × 26 × 4.5 mm 的相机板。D405 背面用 2× M3×0.5（间距 20 mm）固定在相机板上，与旧块相同：M3×8 加 0.5 mm 垫片，旋入约 3.5 mm（数据手册上限 4.0 mm）。螺钉头在腹板两侧，起子能伸进去。
- 相机朝夹爪倾斜 20°，镜头沿手的方向比 URDF 位置往前 38 mm、往里 5 mm。这样镜头和夹爪的相对位置与旧块一致（旧夹爪和新夹爪是同一套硬件）：
  - 镜头在夹爪中面外 65.5 mm、抓取点后方 88 mm，沿开合方向对着两指中间。
  - 这就是旧块照用户参考模型（`挑战杯比赛模型.STEP`）定下的视角：光轴朝豁口倾斜约 20°，镜头在夹爪中面外约 65 mm、指尖后方约 101 mm。
- 两颗螺钉的方向就是 D405 的双目基线方向，沿夹爪开合方向，所以两根手指出现在画面左右两侧，与旧块相同。
- 左右手用同一个零件，不用转向：新 URDF 里两个夹爪是同一个零件，钣金条在各自坐标系里的位置相同。
- 仿真里的腕部相机就是这个安装（`robots/franzi/wrist_mount.py`）：零件和 D405 的外形各加了凸包碰撞体，相机按转接座上的位置渲染。

URDF 原位一列，镜头位置和偏角是按 URDF 的 D405 位置手算的，其余项不适用；转接座一列见 `mount_check.json`，旧块一列取自 2026-10-24 的旧版校核。

画面位置按 D405 彩色视场 84°×58° 计算（数据手册 337029-017 表 3-49）。指垫合拢时沿 CAD 连杆下沉（`robots/franzi/gripper_linkage.py`），夹住零件时比张开时更靠近画面中心。

## 文件与重新生成

- `wrist_d405_mount.stl`：打印用，单位 mm，原点在平台顶面两孔中点；x 朝夹爪外侧，y 沿开合方向，z 沿手指方向。
- `params.json`：设计参数和从 CAD 量出的接口尺寸。平台孔在 CAD 里是 Ø2.9，装之前请在实物上确认孔径和孔距。
- `build_mount.py`：Blender 脚本，按参数生成 STL。
- `check_mount.py`：间隙、对准、画面位置校核，生成 `mount_check.json` 和三张图。要渲染，在 pro6000 上运行。

```bash
/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup --python robots/franzi/hardware/wrist_d405_mount/build_mount.py
```

```bash
MUJOCO_GL=egl python robots/franzi/hardware/wrist_d405_mount/check_mount.py   # pro6000
```
