# 腕部 D405 新相机块（让腕部相机看清夹爪豁口）

## 问题

按夹爪 CAD（`assets/franzi_source/meshes/*_wrist_roll_Link.STL`），D405 背面用两颗 M3 固定在一个小相机块上，相机块挂在 L 形支架下端的叉耳铰链里（铰链轴沿夹爪开合方向）。

- 相机在夹爪中线外侧 58 mm、比指尖高约 111 mm，竖直朝下，光轴和手指平行，没有对着豁口。
- 结果：豁口中心偏离光轴 29°，落在画面最边缘。
- 只绕现有铰链把原相机块往里转，转到约 18° 相机就会碰到夹爪壳体，而对准豁口需要约 22°。所以要换相机块。

## 方案

只换相机块（CAD 中的组件 32），保留 L 形支架（组件 31）和原销轴，机器人上不用打孔，也不用改其他零件。

- 新块的舌板 5.0 mm 厚，插进原叉耳（间隙 5.4 mm）；Ø4.3 孔穿原 Ø4 销轴。舌板端部是绕销轴 R7 的圆头，和原件一样，在叉耳里转动时不会顶到槽底。
- 相机位置照用户提供的参考模型（`挑战杯比赛模型.STEP`，腕部是 D435）。2026-10-24 用户要求视角"类似这个"。
  - 参考模型的腕部相机光轴，绕开合方向朝豁口倾斜 20.2°。
  - 镜头在夹爪中面外 64.7 mm，在指尖后方 101.2 mm；沿开合方向看，正对豁口。
- 搬到 Franzi 上：相机朝夹爪倾斜 20°，相机背面到销轴 34 mm，外移 27 mm。镜头因此在夹爪中面外 65.4 mm、指尖后方 101.4 mm。
- 方案的演变（均为 2026-10-24）：
  - 最初是倾斜 30°、外移 20 mm、背面到销轴 17 mm。长任务 45° 斜向抓取时俯角 75°，几乎往下俯视，夹爪机构占了半个画面。
  - 之后改成 15°，视角斜向下，但相机仍在高处，用户觉得画面太斜。
  - 参考几何把相机放低到更靠近指尖，视线从夹爪机构旁边直接看进豁口，机构基本不入画，夹住的零件和指垫也更大。
- D405 用背面 2× M3×0.5（间距 20 mm）固定：M3×8 加 0.5 mm 垫片，旋入约 3.5 mm（数据手册上限 4.0 mm）。两颗螺钉的方向就是 D405 的双目基线方向，沿夹爪开合方向，所以两根手指出现在画面左右两侧。
- 左右手用同一个零件，右手装时绕竖直轴转 180°。右手 CAD 的支架一侧与左手镜像对称，两侧的校核结果相同。

## 文件与重新生成

- `wrist_d405_mount.stl`：打印用，单位 mm，原点在销轴中心；x 沿销轴，z 向上，左手时 y 朝外。
- `params.json`：设计参数和从 CAD 量出的接口尺寸。
- `build_mount.py`：Blender 脚本，按参数生成 STL。
- `check_mount.py`：间隙、对准、画面位置校核，生成 `mount_check.json` 和三张图。

## 制作与安装

- 打印：PETG 或 PA-CF，至少 4 圈壁、填充 40% 以上。建议侧放，让销孔轴线竖直：这样舌板和腹板的弯曲应力在层内，销孔也最圆。Ø3.4、Ø4.3 两种孔打印后用钻头过一遍。也可以做成 CNC 铝件。
- 安装：
  1. 拆下 D405 的两颗 M3，拔出铰链销轴，取下原相机块。
  2. 把新块的舌板插进叉耳，安装板朝向夹爪（向内倾斜），装回原销轴或螺钉并拧紧。
  3. 用 M3×8 加垫片把 D405 固定到安装板上。USB 线沿腹板走，留出弯曲余量。
  4. 右手用同一个零件，转 180° 安装。
- 装好后检查：
  - 实时画面里两个指尖左右对称，豁口在画面中部。
  - 夹爪全开、全闭以及手腕全程转动时都不碰撞。
  - 物体到镜头不小于 7 cm。

## 上机前要先实测的尺寸（来自 CAD 网格，不是实测）

- 叉耳间隙 5.4 mm，两片叉耳各厚 5.3 mm，销孔 Ø4.0；原相机块舌板厚 5.0 mm。
- 销轴是光销还是 M4 螺钉；原相机块舌板上的孔是光孔还是螺纹孔。如果是 M4 螺纹孔，改用 M4 螺栓加螺母。
- 真机上的相机块如果和 CAD 不同，例如本来就能调角度，以实物为准，把实测尺寸写进 `params.json` 后重新生成。

## 仿真里的安装（2026-10-24 用户确认采用）

- 仿真已经换成新相机块：`sim/wrist_mount.py` 读本目录的 `params.json`，给出相机位姿（与 `mount_check.json` 的 `sim_camera_pose` 一致，相差不到 0.001 mm）、相机块外观（就是 `wrist_d405_mount.stl`）、三块凸包碰撞体和 D405 外壳方盒。`build_mount.py` 和 `check_mount.py` 也从它取几何，改参数只需改 `params.json`，再重新生成 STL、重跑校核和仿真。
- 另外三个和支架无关的仿真问题已经修好：
  1. D405 的光学滚转角按 CAD 改了（左 0°、右 180°），手指现在在画面左右两边。
  2. 长任务的抓取朝向改了，腕部相机在手的上方。
  3. 夹爪按 CAD 连杆运动，合拢时指垫不再悬空（`sim/gripper_linkage.py`）。
